# GRC Risk Assessment Project

## Overview

This project demonstrates a basic Governance, Risk, and Compliance (GRC) assessment for a fictional SaaS company called SecureCloud Solutions.

The project includes identifying cybersecurity risks, scoring those risks based on likelihood and impact, selecting risk treatments, mapping controls to the NIST Cybersecurity Framework (CSF), and creating an access control policy.

## Company

SecureCloud Solutions is a fictional SaaS company with approximately 150 employees that provides cloud-based software to small and medium-sized businesses.

## Project Components

- Company Profile
- Cybersecurity Risk Register
- Risk Scoring Methodology
- NIST CSF Mapping
- Control Implementation Plan
- Access Control Policy

## Framework Used

This project uses the NIST Cybersecurity Framework (CSF) to connect cybersecurity risks and controls to the following functions:

- Govern
- Identify
- Protect
- Detect
- Respond
- Recover

## Skills Demonstrated

- Risk identification
- Risk assessment
- Likelihood and impact scoring
- Risk treatment
- Security control selection
- NIST CSF mapping
- Security policy development
- GRC documentation

## What I Learned

Through this project, I learned how to identify cybersecurity risks and think about the impact they could have on a business. I also learned to consider what assets a company needs to protect, what threats could affect those assets, and what vulnerabilities could make an incident more likely.

I learned how to score risks based on likelihood and impact and use those scores to help determine which risks should receive more attention.

I also learned how to map security controls to the NIST Cybersecurity Framework. This helped me understand how controls can be organized around protecting systems, detecting incidents, responding to attacks, and recovering afterward.

The detailed DDoS mapping was especially useful because it showed me that one risk can involve several different security activities instead of relying on only one control.
